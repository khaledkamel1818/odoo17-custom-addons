# DM HR Offboarding

إدارة الاستقالة وإنهاء الخدمة وإخلاء الطرف والتسوية النهائية ومكافأة نهاية الخدمة في Odoo 17 Community.

يعيد الموديول استخدام:

- بيانات الموظف والهيكل الإداري من `dm_hr_core`.
- العقود الأصلية `hr_contract`.
- العهد غير المالية `dm.hr.custody`.
- سلف/قروض الموظفين وأقساطها إن وجدت.
- سياسات الموافقات الحالية `dm.hr.approval.policy` عبر نوع الطلب `offboarding`.

القائمة:

الموارد البشرية → إنهاء الخدمة.
